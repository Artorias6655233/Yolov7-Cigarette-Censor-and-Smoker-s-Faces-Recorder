# 基于短视频的时序抽烟检测方案

面向场景:禁止明火吸烟的工作环境,摄像头 + 定时任务,每次录制 5~10 秒短视频,
丢给 server 做离线/近实时处理,判断"这段时间内有没有人在抽烟、是谁"。

目标:比单帧判断更准——既减少偶发误检(比如把手机/打火机认成香烟只出现一帧),
也能补救偶发漏检(某几帧手/烟雾挡住了脸)。

现有可复用的模块(本仓库已经跑通,不需要新模型):

- `best_cigarette.pt`(YOLOv7):检测香烟(`smoke` 类)
- `face_detection_yunet_2023mar.onnx`(OpenCV YuNet):检测人脸,鲁棒性好
- `yolov8n-pose.pt`(Ultralytics YOLOv8-pose):检测人体框 + 17 个关键点(含手腕、鼻子/眼睛),
  同时也是做跨帧追踪的入口(`model.track()`,内置 ByteTrack/BoT-SORT)

---

## 整体流程

```
定时任务录制 5~10s 视频
        │
        ▼
按固定帧率抽帧(2~5 fps 即可，不需要全帧率)
        │
        ▼
逐帧跑：香烟检测 + 人脸检测 + 姿态检测(带跨帧track_id)
        │
        ▼
按 track_id 把每帧的“是否被判定为抽烟者”串成时间序列
        │
        ▼
时序判断：① 多帧投票  ② 手腕-鼻子距离节律分析(可选，更强)
        │
        ▼
超过阈值 → 出告警(带track_id、时间戳、代表帧截图)
```

---

## 第一步:抽帧策略

- **帧率**:2~5 fps 足够。抽烟动作是秒级的(一次举烟到嘴大概 1~2 秒),不需要视频原始的
  25/30 fps 全部推理,既浪费算力也没有额外收益。5~10 秒视频抽 2~5 fps,大概只有 10~50 帧
  要跑检测,单张 GPU 或者稍好的 CPU 都能实时处理完。
- **抽帧方式**:均匀间隔抽帧就够(比如每 0.3 秒取一帧),不需要做关键帧检测这种更复杂的预处理。

---

## 第二步:跨帧追踪(每个人要有稳定 ID)

单帧判断的问题不只是准确率,更大的问题是**没有"人"的概念**——如果每帧独立检测,多人场景下
没法知道"这一帧的第 2 张脸"和"上一帧的第 2 张脸"是不是同一个人,时序统计就无从谈起。

解决办法:用 YOLOv8-pose 自带的追踪能力(Ultralytics 已经集成 ByteTrack / BoT-SORT):

```python
from ultralytics import YOLO

pose_model = YOLO("yolov8n-pose.pt")

for frame in frames:  # frames: 抽好的帧序列
    result = pose_model.track(frame, persist=True, verbose=False)[0]
    # result.boxes.id 就是这一帧里每个人的稳定 track_id
    # result.keypoints.data 是对应的关键点(手腕、鼻子等)
```

`persist=True` 表示追踪状态在多次调用之间保持,同一个人在不同帧里会拿到同一个 `track_id`
(除非中途完全离开画面太久)。这样就能把"香烟检测 + 姿态关联"逐帧的结果,按 `track_id`
串成一个人的时间序列。

---

## 第三步:时序判断方法

### 方法一:多帧投票(先做这个,性价比最高)

对每个 `track_id`,统计他在这 10~50 帧里被判定为"SMOKER"(用现有的手腕-最近人脸关联逻辑,
见 `detect_and_box.py` 里的 `find_smoker_faces`)的帧数占比:

```
命中率 = 该 track_id 被判定为 SMOKER 的帧数 / 该 track_id 出现的总帧数
```

- 命中率超过阈值(建议先设 40%~60%,后续用真实数据调)才最终报警,单帧命中不算数。
- 这样能直接过滤掉偶发误检(比如某一帧把手机误判成香烟,只会在孤立的 1~2 帧出现,
  命中率上不去,不会触发告警)。
- 同时也能补救偶发漏检(比如某几帧手挡住了嘴导致没检测到烟,但其他帧检测到了,
  照样能通过命中率阈值)。
- 进阶:除了总占比,也可以要求**连续性**(比如至少连续 3 帧命中),排除时间上过于分散的
  噪声点,更贴近"持续抽烟"而不是"一闪而过的误判"。

### 方法二:手腕-鼻子距离节律分析(更强,能进一步排除误检)

真正抽烟有一个很典型的动作节律:手腕举向嘴部 → 短暂停留 → 放下,循环往复,
每个周期大概 1~2 秒。既然 YOLOv8-pose 每帧都给了手腕和鼻子的关键点坐标,
可以直接算一条时间序列:

```
dist(t) = 该 track_id 在第 t 帧的 “手腕坐标” 到 “鼻子坐标” 的距离(按人体框大小归一化)
```

把这条曲线画出来看,真正抽烟的曲线会有明显的"下探"波形(手靠近脸时 dist 变小,
放下时变大),而且会有一定周期性;像打电话、摸脸这种动作要么只有一次下探不重复,
要么下探后停留时间和抽烟不一样。可以先用简单规则起步:

- 曲线里出现至少一次"局部最小值明显低于起止值"(比如降到人脸尺寸的 0.3 倍以内);
- 这个"靠近"状态持续时间在合理区间(比如 0.3~3 秒,排除瞬间滑过的噪声,
  也排除一直贴着不动这种不像抽烟动作的情况)。

这一层不需要新模型、新依赖,是在已有 pose 输出上做的时序特征分析,可以和方法一叠加使用:
先用方法一筛出候选人,再用方法二做二次确认,降低误报。

### 方法三:专门的视频动作识别模型(备选，一般用不上)

如果前两种方法精度还不够,可以考虑上 3D-CNN / 视频 Transformer(比如 SlowFast、VideoMAE)
做端到端的"抽烟动作"分类。但这需要专门标注的抽烟/非抽烟视频片段来训练,工程量和数据成本
高出一个量级,建议只有方法一、二都验证过、精度确实不够时再考虑。

---

## 第四步:告警内容设计

触发告警时,建议至少记录:

- `track_id`、告警时间戳、命中率(以及节律分析的置信度,如果用了方法二)
- 一张"代表帧"截图(建议选命中率窗口里香烟检测置信度最高的那一帧),
  上面画好香烟框 + SMOKER 人脸框,方便人工复核
- 如果条件允许,把这 5~10 秒的短视频片段也一并留存,便于后续复审或作为再训练数据

---

## 第五步:等你拿到真实素材之后要做的事

1. **先做一批人工标注**:找几段真实场景的短视频(有人抽烟、没人抽烟、有类似干扰动作
   比如打电话/喝水),人工标出"哪几秒确实有人在抽烟"作为 ground truth。
2. **用这批数据来调参数**,而不是拍脑袋定:
   - 抽帧帧率(2 fps 够不够,还是要到 5 fps)
   - 投票阈值(40%还是60%命中率)
   - 节律分析的距离阈值和持续时间区间
3. **先跑方法一,再叠加方法二**,分别记录准确率/召回率的变化,确认节律分析确实带来了增益
   再决定要不要上。
4. 如果发现姿态检测在人员密集/遮挡场景下经常出错(这个仓库测试时在多人合照场景下遇到过,
   YOLOv8-pose 的 n/s 版本会把靠得很近的两个人混淆),再考虑换更大的 pose 模型
   (yolov8m-pose / yolov8l-pose)或者引入专门的多人姿态优化方案。

---

## 小结

| 阶段 | 要做的事 | 是否需要新模型/依赖 |
|---|---|---|
| 抽帧 | 2~5 fps 均匀抽帧 | 否 |
| 追踪 | `YOLO(...).track(persist=True)` | 否(ultralytics 自带) |
| 方法一:多帧投票 | 按 track_id 统计 SMOKER 命中率 | 否 |
| 方法二:动作节律 | 手腕-鼻子距离时间序列分析 | 否 |
| 方法三:视频动作识别 | 端到端视频分类模型 | 是(且需要标注数据) |

推荐路径:**方法一打底 + 方法二加强**,等有真实素材后用人工标注数据调阈值,
大概率不需要走到方法三。
